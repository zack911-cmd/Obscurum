Getting Started

Quickstart

Get GhostShell installed and running on Kali Linux in under five minutes.

1. Install the package

Download and install the latest .deb release directly from GitHub:

bash 
wget https://github.com/zack911-cmd/ghostshell/releases/download/v1.0.0/ghostshell_1.0.0_amd64.deb
sudo dpkg -i ghostshell_1.0.0_amd64.deb
ℹ️

The installer automatically checks for Ollama and installs it if missing. No manual setup required.

2. Launch GhostShell

Search for GhostShell in your Kali applications menu and click to launch. The app will:

  • Auto-start the Ollama service in the background
  • Open the main window with all 14 tools ready
  • Check for your configured AI models

3. Pull your first model

If this is a fresh install, pull at least one model to start chatting:

bash 
ollama pull qwen3-coder:480b-cloud

Model Setup

GhostShell auto-routes prompts between four configurable models. Here's how each one works and how to customize them.

Default model lineup

ModelRoleType
qwen3-coder:480b-cloudPrimary — code, exploits, scriptsCloud
gpt-oss:20b-cloudReasoning — CVE analysis, methodologyCloud
kimi-k2.7-code:cloudHeavy — complex multi-file code tasksCloud
llama3.2:1bOffline fallbackLocal

Pulling cloud models

Cloud models run on Ollama's infrastructure — no local compute needed, but they require an internet connection:

bash 
ollama pull qwen3-coder:480b-cloud
ollama pull gpt-oss:20b-cloud
ollama pull kimi-k2.7-code:cloud

Adding a local fallback model

For offline use or low-RAM machines, pull a small local model:

bash 
ollama pull llama3.2:1b
⚠️

Local models on CPU-only machines with 8GB RAM or less will respond slowly (10-60s per message). Use them only as an offline fallback.

Auto-routing logic

GhostShell scores each prompt against keyword sets to pick the right model automatically:

  • Exploit/payload keywords → routed to the coder model
  • CVE/methodology keywords → routed to the reasoner model
  • You can override this anytime via the model dropdown in chat

Build from Source

Compile your own GhostShell .deb package, or run it as a web app during development.

Clone the repository

bash 
git clone https://github.com/zack911-cmd/ghostshell
cd ghostshell

Install dependencies

bash 
npm install

Run as a web app (development)

bash 
npm run dev # opens http://localhost:5173

Run as a desktop app (development)

bash 
# Terminal 1
npm run dev

# Terminal 2
npm run electron:dev

Build the .deb installer

bash 
npm run electron:build
# output: release/ghostshell_x.x.x_amd64.deb
📦

Requires Node.js 18+, npm, and the system libraries listed in the repo's README under "Build Prerequisites".

Project structure

ghostshell/
├── src/
│   ├── components/    # all 14 feature modules
│   ├── lib/ollama.ts  # Ollama API client
│   └── App.tsx         # layout + routing
├── electron.cjs         # Electron main process
├── preload.cjs           # IPC bridge
└── package.json
